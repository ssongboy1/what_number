# what_number — 최근 주문 보기

음식이 나왔는데 몇 번 테이블 것인지 모를 때, 포스기에서 테이블을 하나씩
눌러보지 않고 **최근 주문 목록을 바로 확인**하기 위한 프로그램입니다.

포스가 주방 프린터로 보내는 주문서를 옆에서 조용히 지켜보다가, 나간 주문서를
시간순으로 모아 화면에 보여줍니다.

```
[포스 PC] ──주문서──> [주방 프린터들]
    └ what_number.exe (지켜보기만 함)
         └── 화면: 이 PC + 주방 폰/태블릿
```

- 배선을 바꾸지 않습니다
- 포스 설정을 바꾸지 않습니다
- 추가로 살 장비가 없습니다
- **이 프로그램을 꺼도 주문서 인쇄에는 아무 영향이 없습니다** (보기만 하므로)

## 프로그램 받기

GitHub 에서 자동으로 만들어 둡니다. 직접 빌드할 필요가 없습니다.

1. [Actions 탭](https://github.com/ssongboy1/what_number/actions/workflows/build-exe.yml) 을 엽니다
2. 맨 위(가장 최근) 줄을 누릅니다 — 초록색 체크 표시가 있어야 합니다
3. 페이지 맨 아래 **Artifacts** 의 `what_number-exe` 를 눌러 받습니다
4. 받은 zip 을 풀면 `what_number.exe` 가 나옵니다

> zip 을 풀지 않고 그대로 실행하면 설정 파일이 저장되지 않습니다. 꼭 압축을 푸세요.

직접 만들고 싶으면 이 저장소를 내려받아 `build.bat` 을 실행하면 됩니다(파이썬 필요).

## 쓰는 법

### 1. 준비물

포스가 **윈도우 PC** 여야 합니다. (안드로이드 태블릿 포스는 이 방식이 안 됩니다)

### 2. 실행

`what_number.exe` 를 포스 PC 바탕화면에 복사하고 **더블클릭**합니다.

- "이 앱이 디바이스를 변경하도록 허용하시겠어요?" → **예**
  (랜카드를 들여다보려면 관리자 권한이 필요합니다)
- 윈도우 방화벽 창이 뜨면 → **액세스 허용**
  (주방 폰에서 접속하려면 필요합니다)

검은 창이 뜨고 브라우저에 주문 화면이 자동으로 열립니다.
포스에서 주문을 하나 넣어보면 몇 초 안에 화면에 나타납니다.

### 3. 주방 폰·태블릿에서 보기

검은 창에 이렇게 표시됩니다.

```
  이 PC에서 보기 : http://127.0.0.1:8710
  주방 폰에서 보기: http://192.168.0.15:8710      ← 이 주소
```

주방 폰이 **같은 와이파이**에 연결된 상태에서 이 주소를 브라우저에 입력하면
같은 화면이 뜹니다. 즐겨찾기에 추가하거나 홈 화면에 바로가기로 만들어 두세요.

### 4. 매번 자동으로 켜지게 하려면

`what_number.exe` 바로가기를 만들어 아래 폴더에 넣어두면 부팅할 때 자동 실행됩니다.

```
Win + R  →  shell:startup  →  엔터
```

## 화면 보는 법

- **큰 숫자** = 테이블 번호
- **주문 카드를 누르면** 프린터로 나간 주문서 원본이 그대로 펼쳐집니다
- 위쪽 **번호 칩**을 누르면 그 테이블 것만 걸러서 봅니다
- 오른쪽 위 **초록 점** = 정상 감시 중 / 빨간 점 = 문제 있음

## 잘 안 될 때

### 주문을 넣어도 화면에 아무것도 안 뜬다

1. 검은 창에 `! ` 로 시작하는 줄이 있는지 봅니다. 있으면 그 내용이 원인입니다.
2. 프린터가 **랜선으로 연결**되어 있는지 확인합니다.
   USB로 연결된 프린터는 이 방식으로 볼 수 없습니다.
3. 포스가 쓰는 포트가 다를 수 있습니다. `config.json` 의 `printer_ports` 에
   포트를 추가해 보세요. (기본값: 9100, 9101, 9102, 515)
4. 포스 PC가 아닌 다른 PC에서 실행하면 아무것도 안 잡힙니다.
   반드시 **주문을 받는 포스 PC**에서 실행해야 합니다.

### 테이블 번호가 "번호 미확인" 으로 나온다

전표의 테이블 표기 방식이 기본 인식 규칙과 다른 경우입니다.
주문 카드를 눌러 원본을 보면 실제로 어떻게 찍히는지 알 수 있고,
`config.json` 의 `table_patterns` 에 규칙을 추가하면 됩니다.

`data\dumps` 폴더에 최근 인쇄 원본이 자동으로 저장되니, 그 파일을 보내주시면
규칙을 맞춰 드릴 수 있습니다.

### "이 주문서는 이미지로 전송되어 글자를 읽을 수 없습니다"

포스가 주문서를 글자가 아닌 **그림으로 그려서** 프린터에 보내는 방식입니다.
이 경우 글자를 읽어낼 수 없어 별도 작업(이미지 복원 + 문자 인식)이 필요합니다.

### 백신이 프로그램을 막는다

패킷을 들여다보는 동작 때문에 일부 백신이 의심스럽게 볼 수 있습니다.
백신의 예외(허용) 목록에 `what_number.exe` 를 추가하세요.

## 설정 바꾸기

exe 를 한 번 실행하면 옆에 `config.json` 이 생깁니다. 메모장으로 열어 고친 뒤
프로그램을 다시 켜면 적용됩니다.

| 항목 | 설명 | 기본값 |
|---|---|---|
| `web_port` | 화면 주소의 포트 번호 | `8710` |
| `printer_ports` | 감시할 프린터 포트 | `[9100, 9101, 9102, 515]` |
| `retention_hours` | 주문 기록 보관 시간 | `48` |
| `idle_seconds` | 이 시간만큼 조용하면 한 장이 끝난 것으로 봄 | `2.0` |
| `encoding` | 글자 인코딩. 비우면 자동 판별 | `""` |
| `open_browser` | 시작할 때 브라우저 자동 열기 | `true` |
| `table_patterns` | 테이블 번호 인식 규칙 (정규식) | 아래 참고 |

`table_patterns` 는 목록 위쪽에 있는 규칙이 먼저 적용됩니다. 각 규칙은 숫자
한 개를 괄호로 잡아야 합니다. 예를 들어 전표에 `[ 8 번 ]` 처럼 찍힌다면
`"\\[\\s*(\\d{1,3})\\s*번"` 을 목록 맨 앞에 넣으면 됩니다.

## 알아둘 점

- **주문 취소·수정은 반영되지 않습니다.** 프린터로 나간 주문서만 보는 구조라,
  포스에서 취소한 주문도 목록에는 남아 있습니다. "방금 뭐가 나갔는지" 확인하는
  용도로 쓰세요.
- **전표에 개인정보가 있을 수 있습니다.** 배달 주문서에는 전화번호와 주소가
  찍힙니다. 그래서 기록은 기본 48시간만 보관하고 자동으로 지웁니다.
  `retention_hours` 로 더 짧게 줄일 수 있습니다.
- 같은 주문서가 주방·바 등 여러 프린터로 나가도 목록에는 **한 건**으로 묶입니다.

## 개발자용

외부 패키지 없이 파이썬 표준 라이브러리만 사용합니다.

```bash
# 테스트
PYTHONPATH=src python -m unittest discover -s tests

# 포스 없이 화면만 확인 (가짜 주문 8건)
PYTHONPATH=src python -m what_number --demo

# 저장된 인쇄 원본으로 인식 결과 확인
PYTHONPATH=src python -m what_number --replay data/dumps/*.bin

# exe 만들기 (윈도우)
build.bat
```

### 구성

| 파일 | 역할 |
|---|---|
| `sniffer.py` | 윈도우 raw socket(SIO_RCVALL)으로 패킷을 읽는다 |
| `reassembly.py` | TCP 조각을 모아 전표 한 장 단위로 되돌린다 |
| `escpos.py` | ESC/POS 제어 명령을 걷어내고 글자만 남긴다 |
| `orders.py` | 전표 글자에서 테이블 번호·항목을 뽑는다 |
| `store.py` | SQLite 저장, 중복 묶기, 오래된 기록 정리 |
| `web.py` | 주문 화면과 조회 API |
| `app.py` | 위 조각들을 하나로 엮고 실행한다 |
